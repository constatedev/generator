МАТЕРИЯ / DECAL STUDIO

Детали, которые работают вместе.

Одиннадцать процедурных типов декалей, многослойный шум, эрозия и микрофактура. Это процедурные материалы, а не фотографии или AI-генерация по тексту.

Новые повреждения: царапины с направлением и длиной, вмятины с глубиной и поднятым краем, масляные пятна и копоть. Влажность меняет roughness пятен, осадок усиливает пигмент по краю. Вмятины передаются normal/height, без изменения силуэта стены.

3D: перетаскивайте для вращения, колесо или pinch — для приближения. Кнопка ⌂ сбрасывает камеру, Home делает то же; клавиши +/− меняют масштаб. Слева меняется декаль, справа — только сцена. Положение, поворот и свет не запекаются в экспорт.

2D: нажмите на любую карту. Albedo экспортируется с прозрачностью; Mask — её отдельная чёрно-белая версия. Нормали в формате OpenGL +Y. Остальные карты непрозрачные, с нейтральными значениями вне декали.

PBR: Albedo — sRGB, остальные карты — линейные данные. Roughness/AO/Metallic записаны одинаково в R/G/B. Normal, Height и AO выведены из процедурного рельефа, а не измерены с реального материала. Height не изменяет геометрию 3D-превью.

Своя стена: загрузите Base Color справа под выбором поверхности. Остальные карты необязательны: Normal, Roughness, AO, Metallic и Emission. Можно настроить повторение и силу карт. Для ORM назначьте один файл в AO/Roughness/Metallic: используются R/G/B соответственно. Свечение Emission видно на поверхности, но не освещает всю сцену. Файлы локальные, не включаются в экспорт декали или JSON и после перезагрузки требуют повторной загрузки.

Экспорт: настоящие 1K и 2K, генерация заново в выбранном размере. ZIP содержит семь PNG и JSON параметров. JSON можно загрузить обратно. Настройки сохраняются в браузере.

Вьюпорт использует настоящую 3D-сцену Three.js. Декаль — прозрачная плоскость перед плоской стеной, а не проекция на произвольную геометрию. Экспортированные карты не включают текстуру стены. Для работы 3D необходим WebGL2; при его отсутствии доступен просмотр 2D.
